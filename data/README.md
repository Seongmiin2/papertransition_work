# 데이터 수집 및 관리 규칙

> 이 문서는 이전 버전이 비-UTF-8 인코딩으로 저장되어 한글 본문이 전부 `?`로 손상된 상태로 발견되었습니다. 아래 내용은 남아있던 구조(제목, 목표 수치, 파일명 규칙, 예시 명령)를 근거로 다시 작성한 것이며, 원문과 문장이 정확히 같다는 보장은 없습니다.

원본 PDF는 `data/raw_pdfs/`에 둡니다. 이 폴더의 `*.pdf` 파일은 Git에 올리지 않습니다(`.gitignore`의 `*.pdf` 규칙 참고). `samples/`와의 차이: `samples/`는 테스트에서 쓰는 기준(golden) PDF 1건을 보관하는 곳이고, `data/raw_pdfs/`는 학습·검증용으로 계속 늘어나는 원본 PDF 모음입니다.

## 수집 목표 수량

- 1차 baseline: 학교·학년이 다른 시험지 PDF 10건
- 확장 목표: 학교·학년이 다른 시험지 PDF 50건
- 수식 학습용: 수식이 포함된 crop/LaTeX 쌍 3,000개
- validation: 별도 문서 기준 500개
- test: 별도 문서 기준 500개

## PDF 요건

- 스캔 또는 인쇄된 A4 시험지
- 저작권·개인정보 문제가 없는 자료만 사용
- 한 시험당 한 PDF 파일
- 학생 이름 등 개인정보가 포함된 경우 제거 또는 마스킹 후 사용
- 해상도는 200~400 DPI 권장
- 손상되거나 페이지가 누락된 파일은 제외
- 중복 PDF는 제외

## 라이선스·출처 확인

- 사용 목적, 출처, 저작권자, 사용 동의 여부 확인
- 상업적 재배포가 금지된 자료인지 확인
- 학교·학년별로 문항 유형과 난이도가 고르게 섞이도록 확인
- 개인정보 처리가 끝나지 않은 자료는 baseline에서 우선 제외

## 파일명 규칙

`학교_학년_연도_학기시험_번호.pdf`

예: `중학교_중3_2025_1학기기말_001.pdf`

## 실행 예시

```powershell
.\.venv\Scripts\Activate.ps1
scan2hwpx convert "data\raw_pdfs\중학교_중3_2025_1학기기말_001.pdf" --formulas --output "output\001.hwpx"
scan2hwpx formula-audit "output\formula_training.jsonl"
```

`formula-audit` 결과에서 수식이 2개 이상 검출된 문서를 우선순위로 수집·검수합니다.
